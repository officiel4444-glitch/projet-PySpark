# PySpark Logistic Regression Pipeline

This project demonstrates a simple end-to-end machine learning pipeline using PySpark MLlib.

## Features
- Data loading with Spark DataFrame
- Feature vectorization using VectorAssembler
- Binary classification with Logistic Regression
- ML Pipeline construction
- Model evaluation using AUC (ROC)

## Requirements
- Python 3.x
- Java 8 or 11
- PySpark

## Installation
```bash
pip install pyspark
